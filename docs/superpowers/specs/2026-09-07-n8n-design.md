# n8n Self-Hosted Automations

**Date:** 2026-09-07  
**Status:** Approved

## Goal

Add n8n to the productivity stack as an always-on workflow automation platform, accessible at `n8n.aritra.fyi`. No CF Access — n8n's own auth protects the editor, and webhooks from external services work unobstructed.

## Scope

- New n8n service in `stacks/productivity/docker-compose.yml`
- New env vars in `stacks/productivity/.env`
- New ingress rule in `stacks/infra/cloudflared/config.yml`
- Add to Glance monitor widget
- DNS record (one-time, on server)

## Design

### Service

Single `n8n` container. SQLite for the database — stored at `/opt/n8n` on the NVMe, no dependency on the shared postgres. Self-contained and easy to back up.

```yaml
n8n:
  image: n8nio/n8n:latest
  container_name: n8n
  environment:
    N8N_HOST: n8n.aritra.fyi
    N8N_PORT: 5678
    N8N_PROTOCOL: https
    WEBHOOK_URL: https://n8n.aritra.fyi
    GENERIC_TIMEZONE: ${TZ}
    N8N_ENCRYPTION_KEY: ${N8N_ENCRYPTION_KEY}
  volumes:
    - /opt/n8n:/home/node/.n8n
  restart: unless-stopped
  networks:
    - server-net
```

### New env vars (`stacks/productivity/.env`)

```bash
N8N_ENCRYPTION_KEY=<strong-random-secret>
```

### Routing

Cloudflared ingress rule added to `stacks/infra/cloudflared/config.yml`:

```yaml
- hostname: n8n.aritra.fyi
  service: http://n8n:5678
```

DNS record (one-time):
```bash
cloudflared tunnel route dns oryx n8n.aritra.fyi
```

Restart cloudflared to pick up new ingress:
```bash
oryx-refresh infra cloudflared
```

### Glance

Add to the monitor widget in `stacks/infra/config/glance.yml`:
```yaml
- title: n8n
  url: https://n8n.aritra.fyi
  icon: si:n8n
```

### Data directory

```bash
sudo mkdir -p /opt/n8n
sudo chown -R 1000:1000 /opt/n8n
```

## Access

- **URL:** `https://n8n.aritra.fyi`
- **Auth:** n8n's own login (set up on first visit)
- **Webhooks:** fully accessible at `https://n8n.aritra.fyi/webhook/...` with no auth gate

## Backup

`/opt/n8n` contains the SQLite database and all credentials. Add to the existing backup script alongside other `/opt/` directories.
